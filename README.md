# IDRGP 2025 — Página (GitHub Pages)

Página estática para comunicação interna (SEPLAN/CPMA) com os mapas e gráficos do **IDRGP 2025**.

## Como publicar no GitHub Pages (opção simples)

1. Suba a pasta `GIT_HUB_2025` para um repositório no GitHub.
2. No GitHub: **Settings → Pages**.
3. Em **Build and deployment**, escolha:
   - **Source**: *Deploy from a branch*
   - **Branch**: `main` (ou `master`)
   - **Folder**: `/GIT_HUB_2025`
4. Aguarde o GitHub gerar o link.

## Onde editar

- Conteúdo principal: `GIT_HUB_2025/index.html`
- Estilos (paleta/identidade): `GIT_HUB_2025/assets/css/styles.css`
- Modal de zoom nas imagens: `GIT_HUB_2025/assets/js/main.js`
- Imagens e PDFs:
  - `GIT_HUB_2025/assets/img/maps`
  - `GIT_HUB_2025/assets/img/graphs`
  - `GIT_HUB_2025/assets/docs`
