# IDRGP 2025 — Relatórios, Mapas e GitHub Pages

Repositório oficial do **IDRGP 2025**, reunindo processamento, análise e publicação de:

* Relatórios técnicos
* Mapas temáticos
* Gráficos e indicadores
* Planilhas consolidadas
* Arquivos geoespaciais
* Página pública no GitHub Pages

Projeto desenvolvido para apoio à comunicação técnica e institucional da **SEPLAN/CPMA**.

---

## Estrutura principal

| Arquivo/Pasta    | Descrição                 |
| ---------------- | ------------------------- |
| `IDRGP_2025.Rmd` | Relatório principal       |
| `resultados/`    | Exportações geradas       |
| `GIT_HUB_2025/`  | Página pública do projeto |
| `*.R`            | Scripts auxiliares        |

---

## Produtos gerados

* PNGs em alta resolução
* Planilhas `.xlsx`
* GeoPackages e Shapefiles
* Página web pública para divulgação

---

## Execução

1. Abrir o projeto no RStudio
2. Revisar os caminhos das bases no `IDRGP_2025.Rmd`
3. Executar o **Knit**

---

## Publicação

O projeto pode ser publicado diretamente via **GitHub Pages** utilizando a pasta:

```bash
GIT_HUB_2025/
```

---

## Objetivo

Centralizar e automatizar a geração dos produtos do **IDRGP 2025**, garantindo padronização, transparência e facilidade de atualização.
